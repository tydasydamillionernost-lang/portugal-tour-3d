# Португалия и юг Европы — 3D-презентация

Презентация туристического тура: Лиссабон, Синтра, Порту, долина Дору, Алгарве, Севилья и Рим, с вылетом из Улан-Удэ.

**Открыть:** https://tydasydamillionernost-lang.github.io/portugal-tour-3d/

Прокручивайте страницу — камера летит над 3D-глобусом по маршруту. Стрелки ↓ / ↑ переключают слайды.

Всё в одном файле `index.html`, работает и без интернета.

Использовано: [three.js](https://threejs.org) (MIT), карты [Natural Earth](https://www.naturalearthdata.com) через world-atlas (общественное достояние), шрифты Prata, Onest и JetBrains Mono (SIL Open Font License).
