# Португалия и юг Европы — 3D-презентация

Презентация туристического тура: Лиссабон, Синтра, Порту, долина Дору, Алгарве, Севилья и Рим, с вылетом из Улан-Удэ.

**Две версии:**
- Карта-глобус: https://tydasydamillionernost-lang.github.io/portugal-tour-3d/
- Вид из космоса (снимки со спутника, ночные огни городов): https://tydasydamillionernost-lang.github.io/portugal-tour-3d/sputnik/

Прокручивайте страницу — камера летит над 3D-глобусом по маршруту. Стрелки ↓ / ↑ переключают слайды.

Каждая версия — один файл `index.html`, работает и без интернета.

Использовано: [three.js](https://threejs.org) (MIT), карты [Natural Earth](https://www.naturalearthdata.com) через world-atlas (общественное достояние), снимки NASA Blue Marble и Black Marble (NASA GIBS, общественное достояние), [Sentinel-2 cloudless](https://s2maps.eu) by EOX IT Services GmbH (Contains modified Copernicus Sentinel data 2016, CC BY 4.0), шрифты Prata, Onest и JetBrains Mono (SIL Open Font License).
